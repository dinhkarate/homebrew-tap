# dinhkarate/tap

Homebrew formulae for my tools.

> Experimental. keyshroud's supported install is `npm install -g keyshroud`; this formula is not
> part of its documentation yet.

```bash
brew install dinhkarate/tap/keyshroud
```

| Formula | What it is |
|---|---|
| `keyshroud` | [keyshroud](https://keyshroud.dev): AI coding agents use your API keys without ever seeing them |

The formulae install the same package that `npm install -g` does, with Homebrew's Node. A workflow
here follows the npm releases, so `brew upgrade` gets a new version within a few hours of its release.
